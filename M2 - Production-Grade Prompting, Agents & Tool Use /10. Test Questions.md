7. A development team is refactoring a customer service agent from an in-context memory model to a summarized memory pattern using external storage. What primary architectural trade-off should the team expect?

* A) Per-turn response latency will drop to zero, but API token costs will increase exponentially across long sessions.

8. When ingesting multi-page PDF documents into Claude via the Messages API, what is the recommended native API configuration?

* A) Rasterize each PDF page into high-resolution JPEG images and send them inside a single `image` content block array.
* B) Pass the PDF as a `document` content block type (`type: "document"`) with Base64 encoding or a file location source.
* C) Extract raw unformatted text using local OCR and pass it as an inline system message inside `CLAUDE.md`.
* D) Wrap the PDF in a `file_vector` content block and enable the `skills-2025-10-02` beta header.

--- ANSWER KEY ---

Question 1: A

Explanation: Using the patch token formula $\lceil \text{width} / 28 \rceil \times \lceil \text{height} / 28 \rceil$: $\lceil 1000 / 28 \rceil = \lceil 35.71 \rceil = 36$ and $\lceil 1500 / 28 \rceil = \lceil 53.57 \rceil = 54$. Multiplying $36 \times 54 = 1,944$ visual tokens.

Question 2: B

Explanation: Subagents start with a clean context window containing no parent chat history or loaded Skills, but automatically inherit the parent session's execution and tool permission context.

Question 3: C

Explanation: `CLAUDE.md` is loaded unconditionally into the context window at startup to enforce global project rules, whereas `SKILL.md` exposes only its `name` and `description` frontmatter at startup and loads full instructions into context only when requested.

Question 4: D

Explanation: The Message Batch API handles high-volume, non-real-time asynchronous workloads via JSONL files, bypassing standard synchronous rate limits and providing a 50% discount on token pricing.

Question 5: B

Explanation: Executing Skills via the Messages API requires the beta headers `code-execution-2025-08-25` and `skills-2025-10-02`, and execution occurs within a sandboxed remote code execution container.

Question 6: C

Explanation: Passing inline Base64 strings inside the message history array re-transmits the complete encoded image string on every API call, causing unnecessary network payload bloat and higher transport latency.

Question 7: B

Explanation: Summarized memory compresses past interactions to reduce per-turn token usage, but risks losing granular facts or specific variables if the summarization prompt does not explicitly preserve them.

Question 8: B

Explanation: Native PDF support in the Messages API requires using the `document` content block type (`type: "document"`), which preserves native document structure and layout without requiring page rasterization.
